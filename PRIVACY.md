# Privacy

Markora captures and edits images locally. Recent captures are kept locally in the app's WebView profile; automatic image saving is off by default. Export or copy images only when requested. Your screenshots are not uploaded by the editor or capture tools.

Optional Gemini OCR sends the current edited image to Google's Gemini API only when you press Extract text. It requires internet access and your own API key. Google's terms, data processing and API charges apply. The key is kept in Windows Credential Manager and is not included in release files or project documents.

Optional update checks (enabled by default and configurable in Settings) query GitHub Releases (`api.github.com` / `github.com`) for the latest Markora version number and download link without sending personal data, screenshots, or device identifiers.

Markora does not include analytics or telemetry. GitHub downloads and the Windows WebView2 runtime have their own privacy policies.
