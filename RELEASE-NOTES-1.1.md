# Markora 1.1

## العربية

- أضفنا «التقاط بمؤقت» إلى قائمة «لقطة جديدة» في المحرر.
- ارسم السهم بالسحب أو بنقرتين لتحديد بدايته ونهايته. اضغط `Esc` لإلغاء النقطة الأولى.
- انقر على حدّ الشكل بأداة الرسم نفسها لتحديده وتعديل خصائصه. السحب من الحدّ يرسم شكلًا جديدًا. تعديلات الأداة بعد الرسم تُطبّق على الرسم التالي.
- ابدأ الكتابة مباشرة في موضع النقر. تبقى نقطة البداية ثابتة عند التبديل بين العربية والإنجليزية. يمكنك تحريك النص داخل الإطار وتثبيته باستخدام زر `Ctrl` الأيمن أو الأيسر مع `Enter`.

## English

- Open Timed capture from the editor’s New capture menu.
- Draw an arrow by dragging or clicking its two endpoints. Press `Esc` to cancel the first point.
- Click a shape’s outline with its drawing tool to select it and edit its properties. Drag from an outline to draw a new shape. Tool settings apply to the next drawing after you finish.
- Type immediately where you click. The starting point stays fixed when switching between Arabic and English. Move text inside an outline and confirm it with either Ctrl key plus Enter.

Windows x64 packages include an installer, a portable ZIP, and SHA-256 checksums. With automatic update checks enabled, Markora checks GitHub when it starts. Download and install from the release page.
